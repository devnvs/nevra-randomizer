## 📌 About The Project

**NEVRA RANDOMIZER** is an interactive web application focused on randomness generation and user interaction through a modern and futuristic interface.

The project was built to combine:

- Dynamic interaction
- Fast response
- Minimalist cyber aesthetics
- Smooth user experience
- Responsive design

Created as part of the NEVRA SYSTEMS ecosystem, the application demonstrates front-end development concepts using clean structure and interactive JavaScript logic.

## ⚙️ Running Locally

Clone the repository:

```bash

```

Access the folder:

```bash
cd nevra-randomizer
```

Open the `index.html` file in your browser.
